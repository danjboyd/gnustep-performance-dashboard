# Base TLS carry patches

These eight patch files reproduce the Base carry set from the released GNUstep
CLI v0.1.5 SDK input, on Base `d898f703e618b86f9b7ecb0f05a257cb6ed3ffac`.
Their exact bytes were checked against the recorded SHA-256 identities. The
custom draft lock lists every file and its application order explicitly.

The source baseline is the public gnustep-cli-new build source at `9a40812`.
This preserves the original patch authorship and descriptions. It does not
assert that a new custom SDK has been built or qualified. The draft lock is
unofficial and does not change the v0.1.6 release inputs.
