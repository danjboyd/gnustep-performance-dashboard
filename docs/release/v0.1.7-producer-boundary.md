# Unsigned producer boundary — review item (b)

Branch/tag-triggered Release is now an unsigned producer only. Its committed
packaging/linux/release-production.json selects managed or custom-csd
explicitly; missing/invalid selection fails, and the custom path cannot fall
back to the managed SDK. The version must match package.version, including
when a tag or manual version override supplies it.

There is no secret context, real signing command, signing-job call or write
permission in release.yml, for push, tag or workflow_dispatch. The managed
producer still consumes only the public update-anchor variable and uploads
unsigned Linux inputs. Real signing requires the later separately reviewed
manual-only workflow; a branch or tag push cannot invoke it through this file.
No key material was inspected or used in this change.

This is an intentional intermediate commit. The selected custom-csd job
currently fails with an explicit unintegrated-handoff error. Item (c) will
replace that guard with the reviewed custom producer and collector. Until
then, do not push/dispatch this intermediate head expecting successful custom
production. Item (d) will add the separately reviewed signing adapter. Neither
item is implemented by this commit, and signed assembly guards are unchanged.

Offline checks cover explicit selection, branch/tag/review versions, missing
or unknown producers, mismatched/injected versions, exclusive producer jobs
and absence of real signing capability in the automatic workflow. Hosted
execution and a new artifact build are unrun. Previous local qualification
remains tied to b6624b9 and its original AppImage/provenance hashes.
