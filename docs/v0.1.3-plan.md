worktree, using the normal secure GNUstep temporary directory and a private

suite by exit status and its final `All N checks passed.` line. Inspect both

## ScreenshotTool investigation

Use a fixed image on a private Xvfb display and an isolated passwd home.
Record a repeatable capture, annotation and save sequence with this source's
recorder (CPU, allocations and leaks); retain traces, target/source/executable
identities, operation timings and screenshots under `out/`. Inspect the
recordings with Performance Dashboard and produce CLI call-tree evidence.
Adwaita and Sombre checks use separate private displays/defaults.

Report measured hot paths or retained allocations to the project lead first.
A hypothesis is not a defect, conservative leak results need confirmation,
and a timed interval alone is not a speedup. Record any Dashboard usability
issues with reproduction steps and assign a v0.1.3 or v0.1.4 follow-up. Any
optional ScreenshotTool prototype uses our own isolated checkout; repeat the
identical workload before/after. No other agent checkout or live desktop is
used, and no patch leaves this machine.
