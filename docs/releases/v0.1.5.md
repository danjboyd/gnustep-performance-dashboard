# Performance Dashboard v0.1.5 — local draft

Planned for Debian 13 x86_64. This draft is not publication approval.
Linux arm64 is deferred to v0.1.6; Windows packages remain outside this release.

- Signed update payloads, with an Ed25519 public key embedded in the package
  and verified signatures required before final release-feed assembly.
- gnustep-packager v0.1.7 packaging pin.
- `gstrace info` symbol-naming coverage across referenced stacks, including
  Allocations-only traces, plus opt-in report coverage with `--symbol-summary`.
- Fixes for reopened embedded fallback-name status and zero return addresses.
- Documentation of conservative Leaks limitations; detector behavior is unchanged.

The released v0.1.4 client has no update-signing public key. Its first update
continues to trust the HTTPS feed and SHA-256 validation, or its existing
AppImageUpdate path; the new signature cannot enforce authenticity on that
old client. Signature enforcement begins with the key-configured v0.1.5
client. The first public-key delivery and actual candidate update acceptance
remain release gates.

The local readiness packet records checks and open gaps. Product keys,
candidate assets and final release approval are still pending.
