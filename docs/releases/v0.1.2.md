## Investigation features

- **Allocation generations:** create named checkpoints, use Mark Now while
  recording, and inspect allocations surviving at a later checkpoint. Marks
  persist with the trace and are preserved by Save As.
- **Compare recordings:** compare independent time ranges or complete
  signpost intervals, including CPU self time and inclusive call paths,
  allocated/leaked bytes, signpost duration and file/network bytes. Values
  are absolute; comparisons do not normalize workload size.
- **Hang evidence:** inspect the selected hang's wall-sampled call tree,
  estimated main-thread CPU and overlapping main-thread I/O. This evidence
  does not establish scheduler state, lock ownership or causality.
- **Source navigation:** open a numbered source view from a stack frame,
  remember source-directory mappings and launch the platform's default
  editor. Matching source/debug information and addr2line are required;
  native PDB lookup and source-line cost attribution are not implemented.

The comparison baseline picker now requests directories only, allowing native
Windows selection of trace bundles. The trace stream remains format v1;
generation metadata is a sidecar that older readers ignore.
