# Performance Dashboard v0.1.0

The first Linux release provides a GNUstep performance viewer, the `gstrace`
CLI, and recording libraries. Record CPU stacks, allocations, conservative
leak candidates, hangs, file/network activity and signposts; inspect timelines
and call trees, export reports, save traces and compare repeated workloads.

## Download and run

Supported host: **Debian 13 amd64**, with X11 or XWayland. Download
`PerformanceDashboard-0.1.0-x86_64.AppImage` and verify it against `SHA256SUMS`.

```sh
sudo apt install libxft2 libxt6t64 libcairo2 libglib2.0-0t64 libdbus-1-3 libunwind8 binutils fonts-dejavu-core
chmod +x PerformanceDashboard-0.1.0-x86_64.AppImage
./PerformanceDashboard-0.1.0-x86_64.AppImage
```

Without FUSE, set `APPIMAGE_EXTRACT_AND_RUN=1`. For the CLI, extract with
`--appimage-extract` and run `squashfs-root/usr/runtime/bin/gstrace`.
The target uses its own libraries; the AppImage bundles the viewer’s GNUstep.
Launching a target needs no administrator privileges. Attaching uses the
optional profiling helper installed through the app or `gstrace install-helper`.

## Compatibility and limits

- Dashboard/framework/CLI builds require Clang and libobjc2 for ARC.
  The C runtime builds with GCC or Clang. Profiling GCC/Clang C targets and
  Clang/libobjc2 GNUstep applications is tested. Debian GCC/legacy-runtime
  Objective-C CPU profiling passes at -O0/-O2; class tagging and Zombies with
  that runtime remain unverified.
- Host libunwind enables optimized-stack unwinding; missing support produces
  a warning. Host binutils supplies source-line lookup. Keep matching debug files.
- Leak reports are conservative candidates. Denied or incomplete scans are
  explicitly unavailable, never presented as a clean bill of health.
- Windows, Ubuntu and other distributions are not supported by this release.
- Packages and update feeds are unsigned. Updates use HTTPS and SHA-256
  integrity checking; no independent signing trust root is configured.

## Validation and licensing

Acceptance covers the regression/unit suite, GCC/Clang compiler matrix,
private-display GUI checks in Adwaita and Sombre, sustained recordings, real
GNUstep workloads, Debian package checks, helper attachment in an isolated VM,
and updater replacement/failure recovery. `acceptance.json` identifies the
final candidate and its checks; provenance identifies the immutable inputs.

The app and tools are GPL-3.0-or-later; the framework, recording agent and
signpost/logging libraries are LGPL-2.1-or-later. Bundled dependencies retain
their licenses. The corresponding-source archive includes the application,
dependency sources, inventory and build instructions.
