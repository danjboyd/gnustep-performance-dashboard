Unpublished release notes for review. The current review package is

## Changes

This release prepares Windows x64 GNUstep launch profiling alongside the
Debian 13 amd64 distribution. Windows review artifacts include an MSI and a
portable ZIP, with dependency inventories, notices and corresponding sources.
Native unwind faults now preserve truncated samples and resume the target
instead of crashing the recorded process.

Embedded symbol snapshots preserve unnamed frame labels so traces retain
matching summaries and exports when moved between Linux and Windows. Native
recording exchange is tested in both directions.

## Distribution and compatibility

- Debian 13 amd64: AppImage; X11 or XWayland. Host libunwind supports
  optimized stack unwinding, and binutils supplies source-line lookup.
- Windows x64: MSI and portable ZIP are review artifacts. Native and package
  tests passed on a Windows Server 2022 developer host. Clean Windows client
  distribution/update acceptance remains blocked; client support is not yet
  qualified for publication.
- Windows kernel/ETW profiling, ARM64, native PDB source lookup and MSVC
  runtime compatibility are outside this release's promises. Windows attach
  remains limited to once per target process.
- Packages and update feeds are unsigned. Update integrity uses HTTPS and
  SHA-256; portable ZIP users update manually.

## Acceptance status

Both RC1 producers, cross-platform CI and strict combined assembly passed.
Linux exact-package checks cover clean Debian execution, real GUI workloads,
Save As/reopen, exports, helper attachment in an isolated VM and local update
replacement/failure recovery. Windows interactive package workflows, complete
update sequencing, positive real-application hangs/signposts and client layout
still need acceptance. Fixture positives do not clear the real-app gates.

See [the acceptance ledger](../v0.1.1-validation.md) for exact evidence and
limits. Final release notes must be reconciled with the approved final hashes;
these RC1 results do not qualify a rebuilt artifact automatically.
