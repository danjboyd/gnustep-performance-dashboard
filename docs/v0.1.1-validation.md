## Evidence required with each handoff

Record the full source commit, clean/dirty build state, toolchain and packager
revisions, artifact filenames and SHA256 hashes. For each acceptance case
record the host OS, command or UI steps, expected and actual result, log/trace/
screenshot locations and exit status where applicable. Distinguish developer
host, hosted runner and clean-client evidence. A rebuilt binary needs new
hashes and acceptance evidence; an older passing run is not transferable.

Use unpublished local versions/feeds for update acceptance. Keep stable and
prerelease feeds separate. Assemble only after both producers identify the
same application commit; assembly itself does not authorize publication.
